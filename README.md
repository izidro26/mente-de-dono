# mente-de-dono

Automação pessoal do processo de escrita e publicação de livros com IA.

- [`diagramacao/`](diagramacao/README.md) — pipeline que gera o PDF de miolo
  (impressão) e o EPUB de um livro a partir de um manuscrito em Markdown ou
  `.docx`, já com margens, capitulares e caixas de destaque calibradas para
  os formatos da Amazon KDP e da UICLAP.
